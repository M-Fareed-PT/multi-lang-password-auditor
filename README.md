# 🔐 Multi-Language Password Strength Auditor & Breach Checker  
A complete password auditing tool implemented in **Java**, **PHP**, and **C# (.NET)**.  
Checks password strength, detects weak patterns, calculates entropy, and compares against breach/wordlists.

This project demonstrates cross-language security engineering.

---

## 🚀 Features
✔ Password entropy calculation  
✔ Weak pattern detection  
✔ Leak/breach wordlist comparison  
✔ Uppercase/lowercase/digit/symbol checks  
✔ Dictionary attack prevention  
✔ Detailed audit result output  
✔ Same logic implemented in 3 languages
